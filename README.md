# @career_restart20s 投稿デザインシステム

Instagramアカウント **@career_restart20s**(20代の転職・キャリア系アカウント)向けの、投稿デザインシステム一式です。
Claude Designにこのリポジトリをリンクし、デザインシステムとして登録することを目的としています。

## 内容

- [`design-system/00-common-principles.md`](./design-system/00-common-principles.md) — 全タイプ共通の設計原則
- [`design-system/01-checklist-diagnosis.md`](./design-system/01-checklist-diagnosis.md) — ①チェックリスト/診断型
- [`design-system/02-before-after.md`](./design-system/02-before-after.md) — ②Before/After比較型
- [`design-system/03-relatable-empathy.md`](./design-system/03-relatable-empathy.md) — ③あるある共感型
- [`design-system/04-data-graph.md`](./design-system/04-data-graph.md) — ④データ・グラフ型
- [`design-system/05-story-comic.md`](./design-system/05-story-comic.md) — ⑤ストーリー漫画型
- [`product/uzuz-neo-product-guide.md`](./product/uzuz-neo-product-guide.md) — 商品理解資料(UZUZ第二新卒・第二新卒エージェントneo)。投稿ネタ・訴求軸の一次情報として参照

## フォーマット共通仕様

- キャンバスサイズ: 1080×1080px(Instagramフィード正方形)
- 顔写真・実在人物の写真は使用しない(顔出しNG方針)
- 1スライドにつき伝えるメッセージは1つまで
- 文字は画面端から60〜80px内側に収める(サムネイル縮小・トリミング対策)

## 使い方

各デザインタイプのMarkdownには、構図・配色・タイポグラフィのルールを記載しています。
投稿を作成する際は該当タイプのルールに従い、「構成」部分(タイトル・本文・CTA等)のみをその投稿の内容に差し替えます。
